# stillsmallstudio / public

A public collection of exploratory notebooks for **learning**, **research**, and **creative experimentation**.

This repository brings together studies in mathematics, language, perception, and digital systems — expressed through code, visuals, and interactive notebooks. Each project is designed to be readable, practical, and insight-driven.

```bash
